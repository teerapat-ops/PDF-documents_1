# Document Desk — PDF Workspace

เว็บแอปสำหรับอ่าน PDF, ใช้ OCR ภาษาไทย/อังกฤษ, ช่วยเสนอจุดแบ่งเอกสาร, ตรวจภาพหน้าจริง และส่งออก PDF แยกชุดหรือ ZIP

## รันในเครื่อง

ต้องใช้ Python 3.10 ขึ้นไป และอินเทอร์เน็ตสำหรับโหลด PDF.js, pdf-lib, Tesseract.js, JSZip และข้อมูลภาษา OCR จาก CDN

```powershell
python server.py
```

จากนั้นเปิด `http://127.0.0.1:8000/` หากเบราว์เซอร์ไม่เปิดเอง ให้คัดลอก URL ไปเปิดด้วยตนเอง กด `Ctrl+C` ในเทอร์มินัลเพื่อหยุดเซิร์ฟเวอร์ พอร์ตอื่นใช้ได้ด้วย `python server.py --port 8080` และปิดการเปิดเบราว์เซอร์อัตโนมัติได้ด้วย `--no-browser`

หากต้องการให้หัวหน้าเปิดทดลองบนเครื่องอื่นจาก Wi-Fi เดียวกัน ให้รัน:

```powershell
python server.py --host 0.0.0.0 --no-browser
```

จากนั้นเปิดดูที่อยู่ LAN ที่เทอร์มินัลแสดง เช่น `http://10.0.20.103:8000/` บนเครื่องหัวหน้า Windows ต้องอนุญาต Python ผ่าน Firewall สำหรับเครือข่าย Private หรือ Domain คอมพิวเตอร์นี้ใช้งาน Wi-Fi แบบ Domain จึงควรใช้ไฟล์ `Start-Document-Desk-LAN.bat` ซึ่งขอสิทธิ์ Administrator และสร้างกฎ Firewall สำหรับ Domain และ Private โดยอัตโนมัติ:

```text
Start-Document-Desk-LAN.bat
```

หากยังเปิดไม่ได้ ให้ตรวจว่าเครื่องทุกเครื่องเชื่อม Wi-Fi ชุดเดียวกัน และ Router ไม่เปิด Client/AP Isolation หรือ Guest Network Isolation แม้เครือข่ายเชื่อมอินเทอร์เน็ตได้ เครื่องอื่นอาจถูกบล็อกไม่ให้เข้าถึงเครื่องภายใน LAN

เพื่อความปลอดภัย ใช้เฉพาะ Wi-Fi ที่เชื่อถือได้ ไม่มี VPN/PIN เชิญบัญชีภายนอก และหยุดเซิร์ฟเวอร์เมื่อทดลองเสร็จ

ไม่ต้องติดตั้งแพ็กเกจ Python เพิ่ม เซิร์ฟเวอร์เปิดเผยเพียง `index.html`, `styles.css` และ `app.js`; ไม่มี endpoint สำหรับอัปโหลดไฟล์ PDF PDF ของผู้ใช้ยังประมวลผลในเบราว์เซอร์เท่านั้น ไม่ถูกส่งไปยังเซิร์ฟเวอร์ ไฟล์หลักของ PDF.js และไลบรารีส่งออกถูกบรรจุไว้ในโฟลเดอร์ `vendor/` จึงไม่ต้องพึ่ง CDN เมื่อใช้งานผ่านเครือข่าย Wi-Fi

## คู่มือการใช้งาน

### 1. เพิ่มไฟล์

เลือกหรือลาก PDF มาวางได้หลายไฟล์ ไฟล์ต้องไม่เกิน 100 MiB ต่อไฟล์ จำนวนไฟล์ที่ทำงานได้จริงขึ้นกับหน่วยความจำและเบราว์เซอร์ หากเพิ่มผิด ให้กด **นำออก** ที่แถวของไฟล์นั้น หรือลบรายการทั้งหมดด้วย **ลบทั้งหมด** แล้วกดยืนยันในหน้าต่างแจ้งเตือน การนำออกเป็นการลบออกจากรายการในแอปเท่านั้น ไม่ได้ลบไฟล์ต้นฉบับออกจากอุปกรณ์

### 2. วิเคราะห์และแบ่งชุดเบื้องต้น

เลือกภาษาสำหรับ OCR แล้วกด **วิเคราะห์ไฟล์ที่รอ** แอปจะทำงานทีละไฟล์และทีละหน้า:

1. อ่านข้อความที่ฝังอยู่ใน PDF ก่อน
2. ถ้าหน้ามีข้อความน้อย จะเรนเดอร์หน้านั้นเป็นภาพและให้ OCR อ่าน
3. ใช้กฎตรวจหัวเอกสาร เลขที่เอกสาร ชื่อบริษัท วันที่ และความต่อเนื่องของเลขที่ เพื่อเสนอว่าหน้าใดน่าจะเป็นจุดเริ่มเอกสารฉบับใหม่ รองรับประเภทเอกสารงานจัดซื้อ เช่น ใบสั่งซื้อ (PO), ใบขอซื้อ (PR), ใบแจ้งหนี้และเอกสารภาษี และจะแยกชุดเมื่อพบหัวเอกสารหรือเลขที่เปลี่ยนชัดเจน แม้หน้าต่อไปไม่มีเลขที่เอกสาร หากตรวจพบหัวเอกสารคนละประเภทชัดเจน เช่น ใบกำกับภาษีต่อด้วยใบเสร็จ ระบบจะเสนอให้เริ่มชุดใหม่ หน้ารายการไฟล์จะสรุปประเภทที่พบในแต่ละไฟล์ เช่น `ใบสั่งซื้อ (PO) · ใบแจ้งหนี้` หลังวิเคราะห์เสร็จ ก่อนส่งออก ZIP ระบบตรวจว่ารวมหน้าของไฟล์ต้นฉบับทุกไฟล์ครบทุกหน้า และจะหยุดด้วยข้อความระบุชื่อไฟล์ที่ยังไม่พร้อมแทนการส่งออกโดยเงียบหรือทำให้ไฟล์หาย
4. จัดทุกหน้าเข้าเป็นชุดเบื้องต้น โดยเก็บหน้าไว้ครบ แม้หลักฐานจะไม่ชัดเจน

ผลนี้เป็นเพียงข้อเสนอ ไม่ได้รับประกันความถูกต้อง 100% คะแนนที่แสดงเป็นจำนวนหลักฐานจากกฎ ไม่ใช่เปอร์เซ็นต์ความมั่นใจ หากหน้าสแกนอ่านหัวเอกสารไม่ออก หรือเอกสารหลายฉบับเป็นประเภทเดียวกันและไม่มีเลขที่ให้อ่าน ระบบอาจยังรวมหน้าไว้ด้วยกัน ผู้ใช้สามารถตรวจและแบ่งชุดเองในขั้นตอนถัดไป

### 3. ตรวจหน้าเอกสารจริงและแก้ไขผล

ส่วน **ตรวจหน้าเอกสารจริง** มีไว้เปิดดูภาพจาก PDF ต้นฉบับของหน้าที่เลือก เพื่อให้เทียบกับข้อความที่อ่านได้ทาง OCR ตรวจว่าระบบอ่านผิดหรือเสนอจุดแบ่งคลาดเคลื่อนหรือไม่ ส่วนนี้ยังใช้เลื่อนหน้า ซูม หมุน และจัดหน้าใหม่ได้

- เลือกไฟล์จากรายการเพื่อเปิดไฟล์นั้น แล้วกดหน้าในรายการเอกสารเพื่อเปิดหน้านั้นในตัวดู PDF
- ดูข้อความที่อ่านได้ในแผงด้านล่างภาพ เพื่อเทียบกับหน้าต้นฉบับ
- ใช้ **แบ่งเอกสารก่อนหน้านี้** เพื่อแยกตั้งแต่หน้าที่เลือกไปเป็นชุดใหม่ หรือใช้ที่หน้าแรกของชุด (ยกเว้นชุดแรก) เพื่อรวมกับชุดก่อนหน้า
- ใช้ตัวเลือกเอกสารเพื่อย้ายหน้าที่เลือกไปอีกชุด หรือใช้ปุ่มเรียงก่อน/เรียงหลังเพื่อเปลี่ยนลำดับหน้าในชุด
- แก้ชื่อหรือประเภทเอกสารบนการ์ดได้ และใช้ **ย้อนกลับ** เพื่อคืนการแก้ไขโครงสร้างชุดล่าสุด

### 4. ส่งออก

ตรวจชื่อชุด จำนวนหน้า และหน้าที่ระบบทำเครื่องหมายว่าควรตรวจเป็นพิเศษก่อนส่งออก จากนั้นเลือกได้ว่าจะ:

- กดปุ่ม PDF บนการ์ดเพื่อดาวน์โหลดชุดนั้นเป็น PDF
- กด **ดาวน์โหลด PDF ทั้งหมดเป็น ZIP** เพื่อรับทุกชุดจากไฟล์ที่วิเคราะห์แล้ว แถบความคืบหน้าจะแสดงระหว่างสร้างไฟล์; ปุ่มจัดการไฟล์และเริ่มวิเคราะห์จะหยุดชั่วคราวจนกว่าจะเสร็จ
- กด **ดาวน์โหลดรายงาน JSON** เพื่อเก็บผลการจัดชุดและรายละเอียดหน้าที่อ่านได้

ก่อนดาวน์โหลด แอปตรวจว่าทุกหน้าต้นฉบับถูกจัดเข้าชุดครบ ไม่มีหน้าซ้ำหรือหน้าหาย การตรวจนี้ยืนยันความครบถ้วนของหน้า ไม่ได้ยืนยันว่าระบบจำแนกเอกสารถูกต้อง ควรเปิด PDF ที่ส่งออกแล้วตรวจอีกครั้งก่อนนำไปใช้งานจริง

## หน้าจอและอุปกรณ์

หน้าเว็บปรับเลย์เอาต์ตามความกว้างหน้าจอสำหรับโทรศัพท์ แท็บเล็ต โน้ตบุ๊ก และเดสก์ท็อป โดยจัดแถบนำทาง เครื่องมือดู PDF แบบสัมผัส และปุ่มส่งออกให้เหมาะกับจอเล็ก การตรวจในเบราว์เซอร์ครอบคลุมขนาดตัวอย่าง 320, 390, 768 และ 1366 พิกเซล การทำงานจริงยังขึ้นกับเบราว์เซอร์ที่รองรับไลบรารี PDF/OCR และการเชื่อมต่อ CDN ตามข้อกำหนดด้านล่าง

## การจัดการข้อมูลและข้อจำกัด

- PDF, ภาพหน้า และข้อความที่อ่านได้ประมวลผลในเบราว์เซอร์ ไม่ถูกส่งไปยัง `server.py` และไม่บันทึกลงดิสก์โดยแอป
- ไลบรารีและไฟล์ภาษา OCR โหลดจาก CDN; ใช้งานครั้งแรกจึงต้องเชื่อมต่ออินเทอร์เน็ต การประมวลผล OCR ใช้ทรัพยากรเครื่องและอาจช้าสำหรับไฟล์ใหญ่
- ตัวแยกประเภทเป็นระบบกฎที่พิจารณาหลายหลักฐาน (หัวเอกสาร เลขที่เอกสาร บริษัท วันที่ และความต่อเนื่องของเลขที่) ไม่ใช่โมเดลที่ผ่านการรับรอง คะแนนที่แสดงเป็นคะแนนหลักฐาน ไม่ใช่ความน่าจะเป็นหรือการรับประกันความถูกต้อง
- ไม่สามารถรับประกันความแม่นยำ 100% ได้ โดยเฉพาะ OCR ภาษาไทยจากภาพสแกนหรือเอกสารรูปแบบใหม่ ระบบจึงแสดงหลักฐานและเปิดให้แก้ไขก่อนส่งออก
- รองรับ Text Layer และ OCR แต่ยังไม่มีการปรับภาพเอียง/เบลอ/จาง การตรวจจับเขตข้อมูลแบบเต็ม การจัดการบัญชีผู้ใช้ หรือการจัดเก็บประวัติงาน
- แอปนี้เป็นเครื่องมือประมวลผลในเครื่องสำหรับผู้ใช้หนึ่งคน ไม่ควรเปิดเซิร์ฟเวอร์ออกสู่อินเทอร์เน็ตหรือใช้แทนการตรวจทานเอกสารทางกฎหมาย/ภาษี
